# Silabus Program Les Informatika

Pemetaan memakai delapan elemen CP Informatika Kurikulum Merdeka: **BK** (Berpikir Komputasional), **TIK** (Teknologi Informasi dan Komunikasi), **SK** (Sistem Komputer), **JKI** (Jaringan Komputer dan Internet), **AD** (Analisis Data), **AP** (Algoritma dan Pemrograman), **DSI** (Dampak Sosial Informatika), **PLB** (Praktik Lintas Bidang).

Catatan: rincian materi per fase perlu dicocokkan lagi dengan dokumen CP dan buku di buku.kemendikdasmen.go.id.

## Tabel Pemetaan Program ke Elemen CP

Keterangan: ● elemen utama, ○ elemen pendukung, ✚ tambahan yang disarankan agar elemen terpenuhi, – tidak tercakup.

|---|---|---|---|---|---|---|---|---|
| Digital Starter | – | ● | ○ | ○ | ○ | – | ● | ○ |
| Coding Starter | ● | – | ✚ | – | ○ | ● | – | ○ |
| Web Developer | – | ○ | – | ● | – | ● | ○ | ● |
| AI Starter | – | ○ | – | – | ○ | – | ● | ○ |

Celah: elemen SK dan JKI baru disentuh sedikit. Program tambahan "Sistem Komputer dan Jaringan" layak dibuat lebih dulu, disusul program "Analisis Data (Spreadsheet)" sebagai jembatan menuju AI Developer.

## 1. Digital Starter (8 sesi)

Prasyarat: tidak ada. Hasil akhir: siswa mampu mengelola file, membuat dokumen, tabel, dan presentasi, serta menjaga keamanan akun.

| Sesi | Topik | Aktivitas dan Output | CP |
|---|---|---|---|
| 1 | Mengenal komputer dan perangkat | Mengidentifikasi perangkat keras dan lunak, menyalakan dan mematikan komputer dengan aman | SK, TIK |
| 2 | Sistem operasi, file, dan folder | Membuat struktur folder tugas dan menamai file dengan rapi | TIK |
| 3 | Mengetik dan mencari informasi di internet | Latihan mengetik, mencari dengan kata kunci, menilai kredibilitas sumber | TIK, JKI |
| 4 | Pengolah kata (Word/Docs) | Membuat laporan satu halaman dengan judul, paragraf, dan gambar | TIK |
| 5 | Spreadsheet dasar (Excel/Sheets) | Membuat tabel nilai dengan rumus SUM dan AVERAGE | TIK, AD |
| 6 | Presentasi (PowerPoint/Slides) | Membuat presentasi 5 slide tentang topik pilihan | TIK |
| 7 | Kolaborasi dengan Google Workspace | Mengerjakan dokumen bersama di Drive, berbagi dan mengatur izin akses | TIK, PLB |
| 8 | Keamanan digital dan etika | Membuat kata sandi kuat, mengenali phishing, jejak digital; presentasi mini proyek akhir | DSI, PLB |

## 2. Coding Starter (10 sesi)

Prasyarat: Digital Starter atau kemampuan komputer dasar. Versi SD: ganti sesi 5–10 dengan Scratch/Blockly. Hasil akhir: siswa membuat program Python sederhana.

| Sesi | Topik | Aktivitas dan Output | CP |
|---|---|---|---|
| 1 | Apa itu berpikir komputasional | Aktivitas unplugged: memecahkan masalah sehari-hari secara bertahap | BK |
| 2 | Dekomposisi dan pengenalan pola | Memecah masalah besar menjadi bagian kecil dan mencari pola | BK |
| 3 | Abstraksi dan algoritma | Menulis algoritma dalam bahasa sehari-hari dan flowchart sederhana | BK, AP |
| 4 | Flowchart: percabangan dan perulangan | Membuat flowchart untuk masalah dengan kondisi dan pengulangan | BK, AP |
| 5 | Hello Python: output, variabel, tipe data | Menulis program pertama yang menampilkan teks dan menyimpan data | AP |
| 6 | Input dan operasi | Program kalkulator sederhana dengan input pengguna | AP |
| 7 | Percabangan (if, elif, else) | Program penentu nilai atau kelulusan | AP |
| 8 | Perulangan (for, while) | Program tabel perkalian dan penjumlahan berulang | AP |
| 9 | List dan fungsi sederhana | Mengolah daftar nilai dan membuat fungsi dengan nama sendiri | AP, AD |
| 10 | Proyek akhir | Membuat game tebak angka atau kalkulator, lalu mempresentasikannya | PLB, AP |

Tambahan saran: sisipkan satu mini-materi di sesi 9 tentang cara komputer menyimpan data (SK).

## 3. Web Developer (12 sesi)

Prasyarat: Coding Starter atau logika pemrograman dasar. Hasil akhir: website portofolio yang sudah online.

| Sesi | Topik | Aktivitas dan Output | CP |
|---|---|---|---|
| 1 | Cara kerja web dan internet | Memahami client-server, URL, DNS, dan HTTP lewat demo di browser | JKI |
| 2 | HTML dasar | Membuat halaman dengan struktur, heading, paragraf, dan daftar | TIK, AP |
| 3 | HTML lanjutan | Menambah gambar, tautan, tabel, dan form | AP |
| 4 | CSS dasar | Mengatur warna, font, dan jarak elemen | AP |
| 5 | CSS layout dan responsif | Flexbox, grid, dan tampilan yang rapi di ponsel | AP |
| 6 | JavaScript dasar | Variabel, fungsi, dan kondisi di browser | AP |
| 7 | JavaScript DOM dan event | Membuat tombol interaktif dan mengubah isi halaman | AP |
| 8 | Array, objek, dan fetch API | Menampilkan data dari API sederhana | AP, AD |
| 9 | Git dan GitHub | Membuat repositori, commit, dan push proyek | TIK, PLB |
| 10 | React dasar | Komponen, props, dan state | AP |
| 11 | Membangun portofolio dan aksesibilitas | Mengerjakan proyek portofolio dengan memperhatikan aksesibilitas dan privasi pengguna | PLB, DSI |
| 12 | Deployment dan presentasi | Mempublikasikan ke GitHub Pages atau Vercel dan mempresentasikan hasilnya | PLB, JKI |

## 4. AI Starter (6 sesi)

Prasyarat: Digital Starter. Hasil akhir: siswa memakai AI secara bertanggung jawab untuk belajar.

| Sesi | Topik | Aktivitas dan Output | CP |
|---|---|---|---|
| 1 | Apa itu AI dan cara AI belajar | Membandingkan aturan manual dengan belajar dari data lewat permainan klasifikasi | TIK, AD |
| 2 | Cara kerja Generative AI dan batasannya | Mencoba chatbot dan mengenali halusinasi serta jawaban keliru | TIK, DSI |
| 3 | Dasar prompt engineering | Menulis prompt dengan peran, konteks, dan format; membandingkan hasil | TIK |
| 4 | AI untuk belajar dan produktivitas | Meringkas materi, membuat latihan soal, dan menyusun jadwal belajar | TIK, PLB |
| 5 | Etika, bias, privasi, dan integritas akademik | Diskusi kasus: kapan AI boleh dan tidak boleh dipakai di sekolah | DSI |
| 6 | Verifikasi informasi dan proyek mini | Memeriksa klaim dengan beberapa sumber, lalu membuat panduan penggunaan AI untuk teman | DSI, PLB |

## 5. AI Developer (12 sesi)

Prasyarat: Coding Starter atau kemampuan Python dasar. Hasil akhir: proyek machine learning dengan demo sederhana.

| Sesi | Topik | Aktivitas dan Output | CP |
|---|---|---|---|
| 1 | Python untuk data | Mengulang Python dan mengenal Jupyter/Colab | AP |
| 2 | NumPy dan Pandas | Memuat, memilih, dan memfilter data CSV | AD, AP |
| 3 | Pembersihan data | Menangani nilai kosong, duplikat, dan tipe data | AD |
| 4 | Visualisasi data | Membuat grafik dengan Matplotlib dan menginterpretasikannya | AD |
| 5 | Statistik dasar dan eksplorasi data | Mean, median, korelasi, dan temuan awal dari dataset | AD |
| 6 | Konsep machine learning | Supervised vs unsupervised, data latih dan uji | AD, BK |
| 7 | Regresi | Memprediksi nilai numerik dengan model regresi | AP, AD |
| 8 | Klasifikasi | Decision tree dan KNN pada dataset sederhana | AP, AD |
| 9 | Evaluasi model dan bias data | Akurasi, overfitting, dan membahas bias dalam data | AD, DSI |
| 10 | Pengenalan neural network | Memahami konsep jaringan saraf dan mencoba model kecil | AP |
| 11 | Proyek: data dan pelatihan model | Mengumpulkan atau memilih dataset, lalu melatih model sendiri | PLB, AD |
| 12 | Demo dan presentasi | Membuat demo sederhana (Streamlit/Gradio) dan mempresentasikan hasil serta batasannya | PLB, DSI |
